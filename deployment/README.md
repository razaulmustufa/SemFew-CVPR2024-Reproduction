# SemFew Streamlit Inference Demo — CIFAR-FS

A 5-way, K-shot interactive inference app using the **team-trained** SemAlign checkpoint and the CVPR 2024 SemFew architecture.

## Bundled model files

The full submission ZIP includes both required checkpoints in `weights/`:
- `ResNet-CIFAR-FS.pth`: **authors' pretrained** ResNet-12 feature encoder (not trained by the student team).
- `semalign_training_checkpoint.pth`: SemAlign trained by the student team for 50 epochs.

When using the **separate GitHub source-only archive**, these files are intentionally excluded to avoid uploading large binary weights to GitHub. Obtain them from the full LMS ZIP or from verified public cloud links and copy both into `deployment/weights/`.

## Run locally on Windows (Anaconda Prompt, recommended)

From the project folder:

```powershell
conda create -n semfewdemo python=3.11 -y
conda activate semfewdemo
python -m pip install -r requirements.txt
streamlit run app.py
```

Alternatively, use a virtual environment with Python 3.10-3.12. GPU is optional — CPU inference is supported.

## How to use

1. Select K = 1, 2, 5, or 10 from the left sidebar. The app uses validation-selected fusion values: 0.83 / 0.68 / 0.47 / 0.37.
2. Choose **five different CIFAR-FS test classes** in the sidebar.
3. Upload **exactly K** labeled support images for each class, followed by one query image belonging to one of those classes.
4. Click **Predict class**. The model computes ResNet-12 features, reconstructs prototype embeddings through the trained SemAlign module using the matching CLIP text embeddings, fuses reconstructed and visual means, then selects the highest cosine-similarity class.

For a valid live demonstration use samples from the held-out `cifar-fs/test/<classname>` folders. Do not use support and query copies of the same image. The app resizes non-CIFAR images to 32x32, but this distribution change can reduce accuracy.

### Inputs
PNG, JPEG or JPG images, ideally CIFAR-FS 32x32 RGB; five distinct class names from the test set; one query image; exactly K support images per selected class.

### Outputs
Predicted class plus cosine similarity scores. They are not probabilities.

## Methodology / academic integrity

- Research method and **original architecture files** `model/res12.py`, `model/dropblock.py`, and `method/SemAlign.py`: from the official SemFew repository by Zhang et al. (CVPR 2024), https://github.com/zhangdoudou123/SemFew. These files are reused, not authored by the student team.
- Semantic embeddings `semantic/cifar100_semantic_clip_gpt.pth`: from the official SemFew repository; not newly generated by the student team.
- ResNet-12 pretrained checkpoint: original authors' public checkpoint, not team trained.
- `semalign_training_checkpoint.pth`: trained by the team in Colab for 50 epochs; the report should state the exact modified workflow and final-epoch checkpoint choice.
- `app.py`: deployment/inference integration assembled for this project; adapt, review and test before claiming it as team code.
- Semantic descriptions are limited to the precomputed CIFAR-FS semantic vocabulary; arbitrary category names are not supported without generating corresponding embeddings.
